# ListingToolbar

Barre collante sous l'en-tête des pages de liste : Filtrer, filtres actifs en pastilles, nombre de pièces, Tri, choix 2 / 3 / 4 colonnes.

`SimeArchives.listingToolbar(count)`. La page fournit une `.sa-grid` et un `filterDrawer()`.

Les pastilles de filtres actifs sont en mono, bordure `rule-strong`. Le choix de colonnes disparaît sous 900px (2 colonnes fixes).
