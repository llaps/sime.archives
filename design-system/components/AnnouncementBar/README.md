# AnnouncementBar

Barre noire au-dessus de l'en-tête, messages qui défilent toutes les 3,6 s, comme sur lacoste.fr.

`SimeArchives.announcementBar([messages])` puis `SimeArchives.init(root)`.

Trois messages au plus : le prochaine récolte, la livraison, une valeur (seconde main, kraft). Texte `on-ink` sur `ink`, style `label`.
